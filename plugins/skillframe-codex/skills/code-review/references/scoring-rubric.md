# 리뷰 이슈 신뢰도 루브릭

각 후보 이슈를 diff, 호출자·callee, 테스트, 실행 결과 중 가능한 근거로 재확인한
뒤 다음 기준으로 판단한다.

- **0:** false positive이거나 기존 문제임을 확인했거나 근거가 없음
- **25:** 가능성은 있지만 검증하지 못함
- **50:** 실제 문제로 보이나 영향이 작거나 실무에서 드묾
- **75:** 이중 확인했고 실제로 발생할 가능성이 높음
- **100:** 직접적인 증거와 재현 경로가 있으며 실무 영향도 명확함

80점 미만의 후보는 리뷰 초안에 넣지 않는다. 75점에 가까운 실질 이슈는 게시 대상에서
제외하되, 사용자가 판단할 수 있도록 별도로 알릴 수 있다.

다음은 기본적으로 제외한다.

- 이 PR이 만들지 않은 기존 문제
- 사용자가 수정하지 않은 라인의 문제
- 의도된 동작으로 설명되는 변경
- 린터·타입체커·컴파일러가 잡는 단순 오류
- 저장소 규칙에 근거하지 않은 취향·일반적 품질 지적
- 재현 근거가 없는 추측
